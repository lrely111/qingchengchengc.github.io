## 一、需求

写一个 `one2n` 命令：接收一个大于 0 的整数 n，输出 1+2+…+n 的结果；不带参数时打印用法。

## 二、代码

```bash
#!/bin/bash
# 计算 1+2+...+n
if [ $# -ne 1 ]; then
    echo "用法: $0 <大于0的整数n>"
    echo "示例: $0 100"
    exit 1
fi
n=$1
if ! [[ "$n" =~ ^[0-9]+$ ]] || [ "$n" -le 0 ]; then
    echo "错误: 参数必须是大于 0 的整数"
    exit 2
fi
sum=0
for ((i=1; i<=n; i++)); do
    sum=$((sum + i))
done
echo "1+2+3+...+$n = $sum"
```

运行结果：`./one2n 10` → `1+2+3+...+10 = 55`；`one2n 100` → `5050`。

## 三、几个细节

1. **`$#` 是参数个数**，`$0` 是脚本名，`$1` 是第一个参数；用它们做参数校验最直接。
2. **`[[ =~ ]]` 做正则匹配**，`^[0-9]+$` 保证是纯数字；`[ "$n" -le 0 ]` 用的是数值比较，不是字符串比较。
3. **退出码要有区分度**：没给参数返回 1，参数非法返回 2，这样调用方能用 `if` 判断失败原因。
4. **变量加引号**：`"$n"`、`"$item"`，否则空值或含空格时会被 Shell 拆词。

## 四、三种执行方式

| 方式 | 需要执行权限 | 运行环境 | 适用场景 |
| --- | --- | --- | --- |
| `./one2n` | 需要（chmod +x） | 新开子进程，按首行 shebang 决定解释器 | 正式运行 |
| `bash one2n` | 不需要 | 新开子进程，显式用 bash 解释 | 调试、临时执行 |
| `source one2n` | 不需要 | 在当前 Shell 内逐行执行 | 加载配置、脚本要改变当前环境 |

`source` 的变量会留在当前 Shell，适合写 `~/.bashrc` 这类配置；而 `./` 的变量出了脚本就消失。

## 五、可改进的地方

- 参数很大时循环会慢，可以直接用公式 `n*(n+1)/2`；
- 缺少 `set -u` 与 `set -e`，严谨的脚本应加上；
- 输出可以用 `printf` 控制格式，便于被其他脚本解析。

顺带一提：把脚本放到 `~/bin` 并加入 `PATH`，就能像系统命令一样直接敲 `one2n 100` 了。
